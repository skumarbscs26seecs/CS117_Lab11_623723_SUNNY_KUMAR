# Storage Estimator

## Purpose
A simple Python program that converts a storage size from gigabytes (GB)
to megabytes (MB). It was created in Lab 10 and is now tracked with Git
and GitHub in Lab 11 of CS-117 Introduction to ICT.

## How to Run
1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run:

       python storage_estimator.py

4. Enter the storage size in GB when asked.

## Example
Input:

    Enter storage in GB: 5

Output:

    Storage in MB: 5120.0
    Storage in KB: 5120000.0

## Note
This program treats 1 GB as 1024 MB.
